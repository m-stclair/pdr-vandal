Basic Usage

To open an image, drag and drop its file(s) onto the window, or click the "Open With PDR" button and drop the file(s) into the dialog (or click "Browse…" to pick them). Click "Open" when the files you want are listed. A single PNG, JPEG or WebP image dropped onto the window opens with the browser reader instead (see "Browser Image Loading" below). If this is the first image you've opened with PDR in the session, PDR will install (10-20 seconds). After opening, the image will display in the main pane. You can zoom the image in and out using mouse or touchpad scroll. When zoomed, you can pan the image by dragging.

If opening a PDS file with detached label (e.g. a PDS4 xml label), add both the observational data file and the label file to the "Open With PDR" dialog, either together or one at a time. PDR will use the information in the label to parse the observational data. The label (.xml or .lbl) is read first; if PDR can't tell which file that should be, it asks you to choose. Files you've added stay in the dialog if you close it, until you open them or click "Clear".

Switching Bands and Objects

If the product you've uploaded has more than one image (like a FITS file with multiple image HDUs), you can switch between them using the "object" dropdown in the upper right-hand corner. If an image has multiple bands/channels, you can swap between them using the "bands" dropdown immediately below the "object" dropdown. If an image has 3 or 4 bands, the "bands" dropdown will also have an "RGB" option that displays the first three bands stacked to RGB.

Effects

The right-hand pane also contains an "effect picker" and an "effect stack" for visual effects like colormapping. You can add effects by clicking on them in the picker. You can open an effect for editing by clicking on it, and remove it by clicking its X button. The "Input Stretch" effect is always pinned at the top of the stack. This effect can clip or stretch the input range for display before rendering or applying other effects. Images with wide value ranges may not be visible without manipulating this effect.

Image Export

You can save the displayed image, including pan/zoom and visual effects, by clicking the "Export PNG" button in the top bar.

Large Images

WebGL will not permit display of images above a certain extent in either dimension. What this extent is depends on your specific browser, GPU, and other aspects of your computing environment. If you attempt to load an image and receive an error related to this, you can try a different browser or computer. Some images may simply be too large.

Similarly, the browser is a fairly memory-constrained environment, and large images, especially images with many bands, may require more memory than is available. If you receive an error related to memory, you may wish to try a different browser or computer. Also, if you have already opened an image this session, you can fully clear pdr-vandal's cache by clicking "close image" and then try again.

Browser Image Loading

If you want to open a "desktop" format image like a JPEG or PNG, you can open it with standard browser features instead of PDR by dropping a single image onto the window. Desktop images will load more quickly this way, but will not support channel flipping or some PDR features like accessing secondary images in MPOs.

Privacy

pdr-vandal runs locally in your browser. It does not upload files to a server for processing. Your files never leave your computer.

    About pdr-vandal

    pdr-vandal is a browser-based viewer and visual effects workbench for planetary and other scientific image data. It combines vandal, a visual effect chain GUI for image enhancement and artistic defacement (optionally including animation via sidechained LFOs), with pdr, which reads Planetary Data System (PDS) and other science data formats.

    pdr-vandal is intended to be a tool for quick browse and visualization of scientific image products. It is not intended to be a full-featured data processing or graphics editing tool, but possibly the first and lowest barrier to entry step in a planetary data analysis toolchain.

    Status

    pdr-vandal is at working beta status. It currently makes no firm guarantees about its stability or completeness.

    Privacy

    pdr-vandal runs entirely in your browser. Your files are never uploaded to a server. The only network access is fetching Pyodide and pdr from a CDN the first time you open a file with PDR.
